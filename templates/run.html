One-click mode: not set up (buttons open GitHub)

Without a token the buttons open the workflow on GitHub, where you press Run workflow. To run straight from here, save a GitHub token in this browser:

  1. Create a fine-grained token: Repository access → Only select repositories → {{ repo }}; Permissions → Actions: Read and write. Nothing else.
  2. Paste it below and save. It is kept in this browser's local storage only and sent only to api.github.com.

Anyone with this token can start these workflows (each run makes one Claude API call); it cannot read secrets or push code. Set an expiry, and use Forget on shared devices.
